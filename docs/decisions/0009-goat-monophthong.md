# 0009: Irish GOAT is a pure [oː]

## Status

Accepted

## Context

Date: 2026-11-26, commit `21dae75`, chosen by ear.

Version 0 of the Irish accent reproduced the original hand-written phones, which glided GOAT.

## Decision

In the Irish accent, GOAT is a pure monophthong [oː] (phone `OH`), applied everywhere, including Danny Boy. No per-song exceptions.

## Consequences

Encapsulated by `accents/irish/accent.json` (version 1).
