# 0005: Plan, then check, then listen

## Status

Accepted

## Context

Date: 2026-11-25, stated by the owner after the female re-casting of Danny Boy.

Every fix in that work was made after a human heard a problem in a render. Each problem came from a constraint of the voice that could have been predicted.

## Decision

Work on a performance proceeds in this order of preference: plan the performance within the voice's constraints; check the plan for compliance before rendering; iterate on human review of renders last. Listening is done on lossless audio, in the full ensemble, and each audible problem becomes a new rule so later plans avoid it.

## Consequences

Project-wide. Drives increments I6 to I9 (feasibility measures, inventory, permissions, preflight).
